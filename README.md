# Grid Legends: Echoes of the Void

Specyfikacja przeglądarkowej gry **2D Turn-Based Tactics / Dungeon Crawler** w TypeScript i Phaser 3, z drużyną trzech Strażników oraz deterministyczną walką na siatce 8×8.

- [Projekt gry: świat, reguły, bohaterowie, przeciwnicy i zakres](docs/GAME_DESIGN.md)
- [Projekt techniczny: architektura, dane, zapis i publikacja](docs/TECHNICAL_DESIGN.md)
- [Plan realizacji i kryteria akceptacji](docs/DELIVERY_PLAN.md)

Dokumenty opisują proponowaną implementację. Repozytorium nie zawiera jeszcze gry, assetów ani uruchamialnego projektu Phaser. Liczby balansowe wymagają testów grywalnego prototypu.

Wiadomość z wymaganiami urywa się przy „System Tury i Punktów”. Dalsze reguły są propozycjami projektowymi, a nie przytoczeniem brakującej części wymagań.
